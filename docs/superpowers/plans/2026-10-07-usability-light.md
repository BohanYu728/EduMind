# EduMind 轻量易用性实施计划

目标：在保留现有接口和流程的前提下，让首次进入页面的用户知道如何开始备课、上传资料和查看下载材料。

架构：新增独立 QuickStart 引导组件，示例只填入现有输入框；App 保留所有会话和生成逻辑。CSS 实施教学工作台配色与双栏/手机纵向布局。

- [x] 新增 frontend/src/QuickStart.tsx，修改 App.tsx 的界面结构和文案，保留输入与现有操作入口。
- [x] 更新 index.css、App.css、index.html 的颜色、字号、布局、focus 与 reduced-motion 规则。
- [x] 执行前端构建与 lint、浏览器验收及后端回归；模拟模型响应验证原有生成、修改和会话操作不受影响，不重复消耗 DeepSeek API。
- [x] 检查桌面与手机截图，修正布局问题并更新本机运行说明。

本轮不实施完整表单向导、自动跳转、详细预览、会话存储改造及新后端接口。
